# ハトだまり

ドット絵の鳩が公園・路上・川沿いにやってくるのを眺める箱庭です。

- ドバト13色＋キジバト2種、計15種の羽色。ぶちやごま模様は1羽ずつ違います
- 歩くときの首振り、地面をつつく、落ち葉を払いのける、羽づくろい、ひなたぼっこ、求愛（ぐるっぽー）
- 止まり木（ベンチ・街灯・電線・自販機・手すり）でひと休み
- 通行人・自転車・猫・車に驚き、仲間につられて一斉に飛び立ち、群れで旋回して戻ってくる
- エサやパンくずをまくと我先にと群がる。パンは持ち逃げや横取りも起きる
- 公園・路上・川沿いのあちこちに落ち葉だまり（画面の広さに応じて2〜8か所）。エサがないときに鳩が寄っていき、葉をかき分けてケヤキやカエデの種・草の実・木の実を見つけて食べる。キジバトは特に好き。エサをまくとそちらが優先。払われた葉は風でまた寄ってきて、実も少しずつ戻る
- 図鑑（ブラウザに保存）、羽音と鳴き声（WebAudioで合成、初期はオフ）
- 鳩の数の上限を右上で変更（1〜1000羽）。−／＋ は段階的に動き、押しっぱなしで連続。数字をタップすると直接入力。ふだんは上限の7割ほどが居つき、エサをまくと上限まで集まる。上限を下げると多いぶんが飛び去る。5羽以下のときは勝手に帰らない

- 右上の「UIオフ」（または H キー）で札や道具箱を隠し、箱庭だけを眺められる。ブラウザで開いているときは全画面にもなる。右下にはアイコンだけの小さな道具箱と「UIを出す」が出て、UIを隠したまま道具を持ち替えられる（しばらく触らないと消え、タップでまた出る）
- スマホのホーム画面に追加すると、アドレスバーなしの全画面アプリとして開ける。一度開けばオフラインでも動く

## 遊び方

`index.html` をブラウザで開くだけです。ビルドも依存もありません。

### ホーム画面に追加する

ホーム画面への追加とオフライン動作には HTTPS で配信されている必要があります（GitHub Pages などにこのフォルダをそのまま置けば足ります。ファイルを直接開いた場合は使えません）。

- Android（Chrome）: メニュー →「ホーム画面に追加」または「アプリをインストール」。全画面（ステータスバーも隠れる）で開きます
- iPhone / iPad（Safari）: 共有 →「ホーム画面に追加」。iOS は完全な全画面に対応していないため、ステータスバーは透過して残ります

| 道具 | 内容 |
| --- | --- |
| 観察 | 鳩をタップすると羽色・性別・いまの行動を表示 |
| エサをまく | 穀物をばらまく |
| パンくず | 大きめのかけら。何度もつつく必要があり、くわえて逃げる鳩も出る |
| 手をたたく | 周りの鳩を驚かせる |

## 構成

- `src/util.js` 乱数・色・ノイズ
- `src/variants.js` 15種の羽色定義
- `src/sprites.js` 鳩のドット絵を手続き的に生成（ポーズごとにラスタライズしてキャッシュ）、人・猫・車など
- `src/scenes.js` 3つの場所の背景生成と歩ける範囲
- `src/pigeon.js` 鳩の行動（状態機械）
- `src/game.js` ループ、入力、湧き、イベント、音、図鑑、UIオフ
- `manifest.webmanifest`・`sw.js`・`icons/` ホーム画面追加用（アイコンは鳩のスプライトから生成）

1ファイルにまとめたいときは `node tools/build-artifact.mjs dist/hatodamari.html`。ホーム画面追加用の部分は別ファイルが要るので、1枚版からは外れます。
